## SearchResults

A 200 response with a paginated list of items matching a search term and filters. It extends [Filtered](/protocol/responses/filtered) with a `searchInfo` property that confirms the search term the server used.

`searchInfo` is omitted when the request had no search term. An empty or whitespace-only `search` value counts as no search term.

### Table

| Parameter      | Type                                                              | Description                                                    |
| -------------- | ----------------------------------------------------------------- | -------------------------------------------------------------- |
| status         | [integer](/protocol/types/numeric#integer)                        | The HTTP status code                                           |
| message        | [string](/protocol/types/string#string)                           | The message to return                                          |
| items          | [Array](/protocol/types/other#array)                              | Items from the current page                                    |
| paginationInfo | [PaginatedResultsInfo](/protocol/pagination#paginatedresultsinfo) | Details about the pagination                                   |
| sortInfo       | [SortedResultsInfo](/protocol/sorting#sortedresultsinfo)          | The sort order of the items                                    |
| filterInfo     | object                                                            | The filters applied to the response items                      |
| searchInfo     | [SearchResultsInfo](#searchresultsinfo)                           | The search term applied to the response items, if one was sent |

### Version headers

The typed `SearchResultsT<ItemsT, FilterT>` response carries the version response headers declared in `Headers.VersionResponse`: `CG-Version-Served`, which reports the full protocol version the response was served in, and the optional `Vary`, `Deprecation`, `Sunset` and `Link` headers. See [Versioning](/protocol/versioning) and the [Versions](/protocol/specification#versions) section of the specification.

### Usage

Use the `SearchResultsT<ItemsT, FilterT>` template to define a 200 response with a paginated list of typed items matching a search within an API operation:

```typespec
import "@common-grants/core";
import "@typespec/http";

using TypeSpec.Http;
using CommonGrants;
using CommonGrants.Pagination;
using CommonGrants.Responses;

model TestModel {
  id: string;
  name: string;
}

model TestFilter extends Record<Filters.DefaultFilter> {
  lastModifiedAt: Filters.DateComparisonFilter;
}

@summary("Search test models")
@doc("Get a paginated list of test models matching a search term and filter")
@post
op searchTest(
  search?: string,
  filters?: TestFilter,
  pagination?: PaginatedBodyParams,
): SearchResultsT<TestModel, TestFilter>;
```
