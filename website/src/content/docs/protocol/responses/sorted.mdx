## Sorted

A 200 response with a paginated list of sorted items.

### Table

| Parameter      | Type                                                              | Description                  |
| -------------- | ----------------------------------------------------------------- | ---------------------------- |
| status         | [integer](/protocol/types/numeric#integer)                        | The HTTP status code         |
| message        | [string](/protocol/types/string#string)                           | The message to return        |
| items          | [Array](/protocol/types/other#array)                              | Items from the current page  |
| paginationInfo | [PaginatedResultsInfo](/protocol/pagination#paginatedresultsinfo) | Details about the pagination |
| sortInfo       | [SortedResultsInfo](/protocol/sorting#sortedresultsinfo)          | The sort order of the items  |

### Version headers

From v0.6.0, the typed `SortedT<T>` response carries the version response headers declared in `Headers.VersionResponse`: `CG-Version-Served`, which reports the full protocol version the response was served in, and the optional `Vary`, `Deprecation`, `Sunset` and `Link` headers. See [Versioning](/protocol/versioning) and the [Versions](/protocol/specification#versions) section of the specification.

### Usage

Use the `SortedT<T>` template to define a 200 response with a paginated list of sorted, typed items within an API operation:

```typespec
import "@common-grants/core";
import "@typespec/http";

using TypeSpec.Http;
using CommonGrants.Pagination;
using CommonGrants.Responses;

model TestModel {
  id: string;
  name: string;
}

@summary("List test models")
@doc("Get a paginated list of test models")
@get
op listTest(...PaginatedQueryParams): SortedT<TestModel>;
```
