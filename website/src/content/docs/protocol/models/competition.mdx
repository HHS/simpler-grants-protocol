## CompetitionBase

Base model for a competition.

A competition is an application process for a funding opportunity. It often has a distinct application period and set of application forms.

From v0.5, a competition links to its opportunity with `opportunity`, an [`OppRef`](/protocol/models/opportunity#oppref) carrying the opportunity's `id` and `title`, in place of the bare `opportunityId` used through v0.4. A competition never carries both.

The table and the JSON Schema tab below render the unversioned schema, which combines the fields of every protocol version, so they list both `opportunityId` and `opportunity` as required. It is a reference across versions, not a contract any single version's payload satisfies. To validate a payload, use the OpenAPI document for its version, such as `/openapi/openapi.0.5.0.yaml`, also browsable on the [API docs](/protocol/api-docs) page.

### Migrating from v0.4

| Version          | Field           | Type               |
| ---------------- | --------------- | ------------------ |
| v0.4 and earlier | `opportunityId` | `uuid`, required   |
| v0.5             | `opportunity`   | `OppRef`, required |

- **Producers:** replace `opportunityId` with an `opportunity` object. Its `id` is the value you sent as `opportunityId`, and its `title` is the linked opportunity's title, so you need that title at hand when you serialize a competition. `identifiers` is optional.
- **Consumers:** read the opportunity's id from `opportunity.id`. Its title arrives with it, so displaying the opportunity no longer needs a second request.
- **Applications are unaffected:** `ApplicationBase` keeps its `competitionId` and `opportunityId` fields.
- **Nested forms change too:** v0.5 replaces each nested form's `name` with `title`. See [migrating forms](/protocol/models/form#migrating-from-v04).

v0.4 and earlier:

```json
{
  "id": "b7c1e2f4-8a3d-4e2a-9c5b-1f2e3d4c5b6a",
  "opportunityId": "b7c1e2f4-8a3d-4e2a-9c5b-1f2e3d4c5b6b",
  "title": "Competition 1"
}
```

v0.5:

```json
{
  "id": "b7c1e2f4-8a3d-4e2a-9c5b-1f2e3d4c5b6a",
  "opportunity": {
    "id": "b7c1e2f4-8a3d-4e2a-9c5b-1f2e3d4c5b6b",
    "title": "Small business grant program"
  },
  "title": "Competition 1"
}
```

Both excerpts omit the other required fields.
