## OppRef

A reference to an opportunity, previewing the key fields a consumer needs to identify it and look it up or join it to another response. Appears wherever another record points to an opportunity, such as the opportunity an [award](/protocol/models/award) resulted from. Since v0.5 it also carries [OppIds](#oppids) under `identifiers`, so a consumer can match the opportunity on a published registry code rather than the hosting system's own id.

## OppIds

A collection of identifiers associated with an opportunity, keyed by registry code. It extends the generic [IdentifierCollection](/protocol/fields/identifier#identifiercollection) with the base identifiers CommonGrants defines for opportunities. Additional registries can be published under `otherIds`.
