**CommonGrants** is an open protocol for sharing information about grant opportunities, applications, and awards across platforms.

## What is CommonGrants?

CommonGrants defines a set of API endpoints and data models for common grant lifecycle tasks — from discovering opportunities to submitting applications and reporting on awards. The protocol is designed to support interoperability by default, while enabling customization to meet the needs of different platforms.

To simplify adoption, CommonGrants is implemented in [TypeSpec](https://typespec.io/), a language for defining APIs that compiles to OpenAPI, JSON Schema, and other common formats. This makes it easy to:

- Validate compliance across implementations
- Generate libraries and tools in different languages
- Extend the protocol without breaking existing tools

We also provide:

- [`@common-grants/core`](https://www.npmjs.com/package/@common-grants/core): A TypeSpec library of canonical models and routes
- [`@common-grants/cli`](https://www.npmjs.com/package/@common-grants/cli): A CLI to scaffold, define, and validate API implementations

## Design principles

CommonGrants is guided by a few key principles:

- **Standardization**: A shared language for describing grants, applications, and awards
- **Extensibility**: A core schema with support for platform-specific extensions
- **Interoperability**: Tools and APIs that work across systems, not just within them
- **Portability**: Grant data that users and organizations can carry with them

## Roadmap

The CommonGrants protocol is evolving in phases, with a focus on real-world usability and adoption.

<Steps>

1. **Done**: Foundation and early adoption
   - Models and routes for opportunities, applications, and awards
   - A core TypeSpec library, CLI, and Python and TypeScript SDKs
   - [Custom fields](/custom-fields/) and [plugins](/plugins/) for platform-specific extensions
   - A mock API for trying routes directly in the [API docs](/protocol/api-docs/)
   - Adoption of the protocol within the [SimplerGrants](https://simpler.grants.gov/) API

   <br></br>

2. **Now**: Award support and developer tooling
   - SDK support and a reference implementation for award data
   - API versioning and migration tools
   - Project templates and a clearer path for community contributions

   <br></br>

3. **Next**: A stable release
   - A v1.0 release of the protocol
   - Public directory of compatible tools and implementations

</Steps>

Want to help shape what comes next? [Vote for features](https://commongrants.fider.io) on our co-planning board.

## Background and inspiration

CommonGrants builds on the design patterns and community principles behind:

- [JSON Schema](https://json-schema.org/): For structured, self-validating data
- [OpenAPI](https://swagger.io/specification/): For generating consistent APIs
- [FHIR](https://www.hl7.org/fhir/): For standardizing complex data across a fragmented ecosystem
- [ActivityPub](https://www.w3.org/TR/activitypub/): For federated interoperability
